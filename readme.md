Планировщик задач (Task Planner) - веб-приложение для управления списком задач. Разработано на языке Python с использованием фреймворка Django и базы данных PostgreSQL.

Функционал приложения

Приложение позволяет создавать, редактировать и удалять задачи. Для каждой задачи можно указать название, описание, срок выполнения и статус («Новая», «В работе», «Выполнена»). Также реализованы поиск по названию, фильтрация по статусу и сортировка по сроку выполнения. Все данные сохраняются в базе данных.

Используемые технологии

Python 3.10 и выше, Django 4.2, PostgreSQL, HTML5, CSS3, а также минимальное количество JavaScript.

Инструкция по установке и запуску

Для работы приложения на компьютере должны быть установлены Python, PostgreSQL и PgAdmin.

Сначала создайте пустую базу данных. Откройте программу PgAdmin, нажмите правой кнопкой мыши на раздел «Databases» и выберите «Create», затем «Database». Введите имя базы данных task_planner_db и сохраните изменения.

Затем откройте папку с проектом в PyCharm или любом другом редакторе кода. Создайте и активируйте виртуальное окружение. В терминале выполните команду python -m venv venv. Для активации на Windows введите venv\Scripts\activate, для Linux или Mac - source venv/bin/activate.

После активации окружения установите необходимые зависимости командой pip install -r requirements.txt.

Далее нужно настроить подключение к базе данных. Откройте файл task_planner/settings.py, найдите блок DATABASES и укажите там свой пароль от PostgreSQL в поле PASSWORD. Логин по умолчанию обычно postgres, а хост - localhost. Убедитесь, что порт указан как 5432.

Когда база данных настроена, примените миграции для создания таблиц. В терминале выполните команду python manage.py migrate. Затем создайте суперпользователя для доступа в админ-панель командой python manage.py createsuperuser и следуйте инструкциям на экране (придумайте логин, электронную почту и пароль).

Для запуска сервера введите команду python manage.py runserver 8080. Откройте браузер и перейдите по адресу http://127.0.0.1:8080/. Приложение готово к работе. Админ-панель доступна по адресу http://127.0.0.1:8080/admin/.
